# AsciiLab v0.3

이미지와 영상을 문자로 다시 그리는 브라우저 기반 ASCII 아트 스튜디오.

**사이트:** https://oyueo-mm.github.io/AsciiLab/

## 실행

Node.js 22.15 이상과 npm이 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

개발 주소는 `http://127.0.0.1:5173/AsciiLab/`입니다.

## 기능

- **Home**: 한글 픽셀 타이틀, 첫 화면의 ASCII 도넛. 이전 대비 3배의 시간 기반 회전 속도(약 0.409rad/s), 30fps 목표, 부하에 따라 24/20fps로 조절. 문자 밀도(180열), 캔버스 크기와 표면 형상을 유지합니다. 일시정지·숨겨진 탭에서는 애니메이션 프레임을 예약하지 않으며, 동작 줄이기 설정을 반영합니다.
- **Image Studio**: 이미지 업로드·드래그 앤 드롭·Ctrl+V 붙여넣기, 내장 달 샘플, 원본/ASCII/비교/텍스트 보기. 밀도, 사용자 문자, 밝기, 대비, 반전, 흑백/민트/원본 색상, 배경, 글자 크기, 줄 간격 조절. **전체 이미지 / 배경색 제거 / 직접 영역 선택 / AI 자동 피사체 선택**, 투명 배경 PNG·TXT·HTML 내보내기, 텍스트·HTML 서식·PNG 클립보드 복사.
- **Video Studio**: 로컬 영상 업로드, HTMLVideoElement + Canvas 실시간 ASCII 프리뷰, 재생/일시정지, 탐색, 음소거, FPS 제한 및 변환 설정. **배경색 제거·스포이트·유사도·경계 부드럽게**, 투명 프레임 PNG 저장과 현재 프레임 텍스트 복사.
- **한글 문자 세트**: 기존 Classic/Dense/Minimal/Custom에 한글 자모·음절 프리셋 추가. Neo둥근모의 Canvas 글리프 밀도를 측정해 명암 순서를 정하고 전각 문자 셀과 줄 간격을 보정합니다. 사용자 문자는 그래핌 단위로 나누어 조합 문자와 이모지를 보존합니다.
- **Gallery**: IndexedDB에 원본과 설정, 썸네일, 텍스트 저장. 새로고침 후 유지, 스튜디오로 다시 열기, 확인 후 삭제.
- 장식용 영문·번호·상단 경로·반복 설명을 제거한 화면, 접이식 사이드바와 모바일 드로어, 접을 수 있는 모바일 설정 패널, 키보드 포커스 표시.

파일은 서버로 업로드되지 않습니다. 폰트와 샘플은 프로젝트에 포함했습니다. 자동 선택을 처음 실행할 때만 Hugging Face에서 공개 모델을 내려받으며, 추론은 브라우저의 별도 Worker에서 수행합니다.

## 구조

```text
src/
  app/                 앱 셸과 HashRouter 라우트
  components/ascii/    공유 프리뷰와 설정 패널
                      마스크 설정과 올가미/스포이트 모달
  components/home/     절차적으로 생성하는 ASCII 애니메이션
  pages/               Home / Image / Video / Gallery
  utils/ascii.ts       픽셀 샘플링·명암 매핑·컬러 렌더링·파일 출력
  utils/mask.ts        이미지·영상 공용 색상 마스크, 원본 좌표 기반 선택 영역
  utils/image.ts       GIF 첫 프레임을 포함한 정적 래스터 디코딩
  utils/heroAnimation.ts 시간 기반 회전과 사전 계산한 도넛 표면
  utils/storage.ts     IndexedDB 저장소
  utils/sample.ts      외부 요청 없는 내장 달 샘플
  assets/              Neo둥근모 픽셀 폰트와 OFL 라이선스
tests/browser.mjs      실제 Edge 브라우저 통합 검증
tests/masking.mjs      마스크·투명 출력·이전 저장 데이터·터치 검증
```

Canvas로 원본을 문자 셀 해상도에 맞게 축소 샘플링하고, RGB의 상대 밝기를 문자 세트에 매핑합니다. 셀 가로·세로 비율로 원본 종횡비를 보정합니다. 컬러 출력은 각 셀의 RGB를 유지하며 알파는 별도 글자 불투명도로 처리합니다. 영상은 요청한 FPS 이내에서 현재 프레임만 변환하며, 탭이 숨겨지면 프레임 변환을 건너뜁니다.

## 피사체 선택

- **배경색 제거:** 원본의 배경을 스포이트로 클릭하거나 제거할 색을 지정합니다. RGB 색상 거리, 유사도 허용치, 부드러운 전이를 사용해 알파 마스크를 만들며 원본 RGB는 바꾸지 않습니다. 영상 스포이트는 현재 프레임을 정지시켜 선택하고, 선택 창을 닫으면 이전 재생 상태를 복원합니다.
- **올가미:** 영역 선택 버튼 또는 ‘직접 영역 선택’에서 마우스/터치로 외곽선을 그립니다. 선은 자동으로 닫히며 ‘영역 적용’을 눌러 확정합니다. 취소, 되돌리기, 다시 그리기, 초기화, 확대, 경계 부드럽게를 지원합니다. 단일 닫힌 영역을 사용하며, 다시 그리면 이전 영역을 대체합니다.
- **자동 피사체 선택:** ormbg 양자화 ONNX 모델(44,315,205 bytes, Apache-2.0)을 지연 로딩합니다. WebGPU를 우선 사용하고 지원하지 않는 연산·환경은 WASM으로 처리합니다. 다운로드·로딩·추론 상태와 취소를 제공하며, 실패해도 올가미와 색상 제거를 사용할 수 있습니다. 민트 오버레이에서 추가/지우기 브러시, 크기·부드러움, 최근 12개 작업 되돌리기, AI 원본으로 보정 초기화, 경계 부드럽게를 조절한 뒤 적용합니다. 모델 비교와 고지는 [docs/v0.3.md](docs/v0.3.md), 라이선스 전문은 [public/licenses](public/licenses)를 참고하세요.
- **좌표와 캐시:** 선택 점과 알파 마스크를 편집용 원본 좌표로 보관합니다. 화면 크기나 문자 밀도·명암 변경으로 재추론하지 않습니다. 자동 결과와 수정본은 각각 무손실 PNG로 압축해 IndexedDB에 저장하고 작품을 열 때 복원합니다. 갤러리 원본도 편집용 원본 크기를 유지합니다. 영상은 작은 프리뷰 샘플 버퍼에 공용 색상 제거를 적용합니다.
- **출력:** 제외된 셀은 반전·밝기·사용자 문자와 무관하게 공백입니다. PNG의 ‘투명 배경’을 켜면 빈 영역 알파가 0이며, 끄면 설정한 배경색으로 채웁니다. HTML도 글자별 마스크 알파와 배경 설정을 유지하고 TXT는 공백으로 출력합니다.
- **저장 호환:** IndexedDB 스키마를 유지합니다. 마스크와 투명 배경 설정이 없는 기존 작품에는 기본값(전체 이미지, 불투명 배경)을 적용합니다. 파일을 새로 업로드하면 이전 파일의 선택 마스크를 초기화합니다.

## 복사와 붙여넣기

- 이미지 스튜디오의 ‘텍스트’는 선택 가능한 `<pre>`와 가로 스크롤을 제공합니다. 내보내기 옆에서 텍스트/서식 포함/이미지 복사를 선택합니다.
- 텍스트 복사와 TXT는 같은 `frame.text`를 사용합니다. 줄바꿈·후행 공백·유니코드를 보존하며 마스크 제외 영역은 공백입니다. 운영체제에 따라 클립보드에서 LF가 CRLF로 표현될 수 있습니다.
- 서식 포함 복사는 `text/plain`과 안전하게 이스케이프한 `text/html`을 함께 제공합니다. PNG 복사는 `image/png`만 제공합니다. 브라우저 권한 또는 형식 지원 문제로 실패하면 텍스트 보기에서 직접 선택할 수 있습니다.
- Ctrl+V는 이미지 파일을 불러옵니다. 입력창·사용자 문자·편집 가능한 영역과 열린 편집 모달에서는 기본 붙여넣기를 가로채지 않습니다.
- 영상의 ‘프레임 텍스트 복사’는 마지막으로 렌더링한 현재 프레임을 복사합니다. 실패하면 해당 프레임의 선택 가능한 텍스트를 표시합니다.
- 일반 텍스트를 받는 프로그램의 글꼴·전각/반각 공백 처리에 따라 정렬은 달라질 수 있습니다. 모양과 색을 유지하려면 HTML 또는 PNG를 사용하세요. 한글은 문장 생성 기능이 아닙니다.

## 검증

`npm test`는 명암·반전·밝기/대비·사용자 문자·투명도·색상·HTML 이스케이프, 색상 마스크·경계 알파·기존 설정 호환, 프레임 수와 독립적인 3배 회전 속도·부하별 갱신 주기를 확인합니다.

로컬 서버를 실행한 뒤 아래 명령으로 브라우저 통합 검증을 실행합니다. Windows의 설치된 Edge를 사용하며, 다른 환경에서는 Playwright 브라우저를 설치하고 `TEST_BROWSER=chromium`으로 지정할 수 있습니다.

```sh
npm run test:browser
```

v0.3 브라우저 검증은 실제 텍스트·HTML·PNG 클립보드, Ctrl+V, 권한 거부 대응, 한글 셀과 TXT 일치, 모델 다운로드 실패, 브러시·되돌리기·초기화·PNG 마스크 복원, 터치, 영상 프레임 복사, 390/768/1440px 텍스트 스크롤을 추가로 검사합니다.

실제 모델 추론은 별도 테스트로 실행합니다. 최초 실행에는 약 44.3MB 모델과 검증 이미지를 `.qa/`에 받습니다. 브라우저에는 같은 모델 파일을 로컬 응답으로 제공해 실제 ONNX 추론과 UI 응답성, 알파 분리를 검증합니다. `AI_GPU=1`이면 WebGPU를 사용하고, 기본값은 GPU를 끈 WASM 실행입니다. `TEST_URL`로 빌드 프리뷰도 지정할 수 있습니다.

```sh
npm run test:ai
```

`TEST_URL`로 프로덕션 또는 프리뷰 URL을 지정할 수 있습니다. 기존 업로드·편집·출력·갤러리·영상 검증을 유지하며, 새 테스트는 장식 문구의 실제 DOM 제거, 사이드바, 도넛 일시정지/탭 숨김/동작 줄이기, 색상 제거와 허용치, 올가미 조작·원본 좌표, 투명 PNG 알파·TXT·HTML, 기존 갤러리 호환, GIF 첫 프레임, 움직이는 영상 배경색 제거, 실제 터치 이벤트, 390/768/1440px 화면 및 콘솔 오류를 검사합니다. 생성한 영상과 다운로드, 화면 캡처는 Git에서 제외된 `.qa/`와 `.qa/v02/`에 남습니다.

## GitHub Pages

- Vite의 `base`는 `/AsciiLab/`입니다.
- `HashRouter`를 사용하므로 `#/image`, `#/video`, `#/gallery` 직접 방문 및 새로고침이 정적 호스팅에서 동작합니다.
- `.github/workflows/deploy.yml`이 `main` 푸시 때 `npm ci`, 단위 테스트, TypeScript 검사와 빌드 후 Pages에 배포합니다.
- 저장소 **Settings → Pages → Source → GitHub Actions**를 사용합니다. 초기 Pages 설정에는 저장소 관리 권한이 필요합니다.
- 저장소 이름을 변경하면 `vite.config.ts`와 `index.html`의 favicon 경로를 함께 수정하세요.

## 제한

- 영상 전체의 GIF/WebM 내보내기는 지원하지 않습니다. 현재 프레임 PNG를 사용할 수 있습니다.
- 색상 제거는 피사체의 같은 색도 제거할 수 있습니다. AI 자동 선택은 사람 이미지에 최적화된 모델이며 복잡한 배경·일반 사물·가느다란 경계에서 잘못 선택할 수 있습니다. 브러시로 보정하거나 올가미를 사용할 수 있습니다. 영상에는 색상 제거만 제공합니다.
- 영상 재생 가능 여부는 브라우저/운영체제 코덱에 따릅니다. H.264 MP4 또는 VP8/VP9 WebM을 권장합니다.
- 이미지는 30MB·8천만 픽셀 이내이며 편집용·갤러리 원본은 긴 변 2400px 이내입니다. AI 입력은 1024×1024이며 결과 알파를 편집용 원본 크기로 복원합니다. 세로 문자 수는 400행까지입니다. GIF는 첫 프레임을 사용합니다.
- 자동 선택에는 Web Worker, OffscreenCanvas, WebAssembly를 지원하는 최신 브라우저가 필요합니다. 첫 실행에는 모델 약 44.3MB와 런타임 WASM 약 27.2MB(압축 전)를 받습니다. 다운로드는 Cache Storage, 같은 이미지의 결과는 메모리에 보관하며 저장 공간이 제한되면 다시 받을 수 있습니다. 느린 기기에서는 추론이 수십 초 이상 걸릴 수 있습니다.
- 갤러리는 이 브라우저에만 저장됩니다. 브라우저 데이터 삭제/저장 공간 회수 시 사라질 수 있으므로 중요한 작품은 파일로 내보내세요.
- TXT는 색상 정보가 없습니다. 색상과 배경을 보존하려면 PNG 또는 HTML을 사용하세요.
