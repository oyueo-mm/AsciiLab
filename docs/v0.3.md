# v0.3 구현·검증 기록

## 모델 선택

| 후보        | 검토 결과                                                                                                                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ISNet / DIS | 일반적인 피사체 분리에 적합한 구조. 코드의 Apache-2.0 고지와 별도로 DIS5K 데이터셋의 연구·교육용 조건이 있어 배포 모델의 출처와 조건을 구분해야 함.                                                                                                    |
| MODNet      | [공식 저장소](https://github.com/ZHKKKe/MODNet)의 Apache-2.0 인물 매팅 모델. 실시간 인물 매팅에 초점이 있어 일반 이미지 스튜디오의 기본 선택에서는 제외.                                                                                               |
| ormbg       | [원본 모델 카드](https://huggingface.co/schirrmacher/ormbg)와 [ONNX 변환 카드](https://huggingface.co/onnx-community/ormbg-ONNX)가 Apache-2.0을 명시. IS-Net 기반이며 사람 이미지에 최적화됨. 명시된 모델 라이선스와 양자화 배포 파일을 기준으로 선택. |

Transformers.js는 전처리·모델 캐시를 제공하지만 이번 작업에서는 ONNX Runtime Web을 직접 사용합니다. 입력/출력 변환이 단순하며 전처리 설정과 GPU/WASM 전환을 직접 제어할 수 있습니다.

- 런타임: ONNX Runtime Web **1.24.3**, MIT. GitHub Pages에 포함된 동일 버전의 asyncify `.mjs`/`.wasm`을 사용합니다. `SharedArrayBuffer`나 서버 헤더를 요구하지 않도록 WASM 스레드는 1개이며 추론 전체를 Worker에서 실행합니다.
- 모델: `onnx-community/ormbg-ONNX`, 리비전 `c491647`, `onnx/model_quantized.onnx`.
- 파일: **44,315,205 bytes** (44.3 MB / 42.26 MiB).
- SHA-256: `ffbcae62a7b675d616e64cb392ee028786c4cf74f83596590fba13733ef00171`.
- 모델 및 고지: Apache-2.0, [배포 고지](../public/licenses/NOTICE.txt). 모델은 변경하지 않았고 최초 사용 시 Hugging Face에서 받습니다.
- 전처리: 모델의 `preprocessor_config.json`에 맞춰 RGB를 1024×1024로 조절하고 1/255로 변환합니다. 별도 정규화는 하지 않습니다. 첫 분할 출력의 [0,1] 값을 알파로 변환하고 원본 크기로 보간합니다.
- WebGPU 어댑터가 있으면 WebGPU와 WASM을 함께 등록합니다. 지원 연산은 GPU에서, 나머지는 CPU에서 처리합니다. 세션 생성·추론 실패 시 WASM으로 재시도합니다.
- 서버로 보내는 것은 공개 모델 다운로드 GET 요청뿐입니다. 이미지·텐서는 Worker에 전송하며 외부 추론 API를 사용하지 않습니다.

## 품질과 제한

실제 호랑이 사진(612×408)에서 몸·얼굴·다리와 배경을 구분한 알파 마스크를 확인했습니다. 검증 결과 약 63%가 제외 영역(알파<20), 33%가 선택 영역(알파>235), 나머지가 부드러운 경계였습니다. 이는 한 장의 기능 검증이며 정량적인 분할 정확도 벤치마크가 아닙니다.

이 개발 환경의 프로덕션 빌드에서 모델 전달·로딩·추론까지 WASM 약 10.4초, WebGPU/WASM 약 17.6초를 관측했습니다. 인터넷 모델 다운로드를 로컬 응답으로 제공한 단일 실행 결과이며 기기 간 성능 비교가 아닙니다. 별도로 실제 Hugging Face 다운로드·CORS·해시 검증과 추론 성공도 확인했습니다. 약 249.7KB의 원본 알파 평면은 약 65KB PNG로 무손실 저장됐습니다.

모델은 사람 이미지 중심으로 학습되어 사물·복잡한 배경·털·반투명 영역·작은 피사체에서 누락이나 배경 포함이 생길 수 있습니다. 민트 오버레이에서 결과를 확인한 다음 추가/지우기 브러시로 보정할 수 있습니다. 올가미와 색상 제거를 유지합니다. 저사양 모바일의 메모리·속도, 브라우저 GPU 드라이버, 네트워크·저장소 제한은 실제 성능에 영향을 줍니다.

문자 밀도·명암·글자 크기는 AI 추론을 다시 실행하지 않습니다. 원본 알파와 보정 알파를 따로 유지하며 갤러리에는 두 결과를 무손실 PNG Blob으로 압축합니다. 기존 IndexedDB 버전과 v0.2 작품을 유지합니다. 편집 원본은 기존 디코더의 긴 변 2400px 한도 안에서 보존합니다.

## 문자·클립보드

한글 자모와 음절은 Neo둥근모를 Canvas에 렌더링해 알파 면적을 측정하고 밀도 순서로 명암을 매핑합니다. 글자 크기와 같은 폭의 셀을 사용하고 줄 간격은 한글에서 최소 1배를 유지합니다. 기존 영문 프리셋은 0.6배 셀을 유지합니다. Custom은 그래핌 단위로 분리해 한글·결합 문자·이모지를 보존합니다.

PNG와 HTML은 고정 셀 폭, 색, 알파를 보존합니다. 일반 TXT·텍스트 클립보드는 동일한 문자 배열과 줄바꿈·후행 공백을 사용합니다. Windows가 클립보드를 CRLF로 반환하는 동작은 검증에서 정규화합니다. 외부 프로그램의 글꼴·공백 폭 때문에 일반 텍스트의 정렬은 달라질 수 있습니다. HTML의 사용자 문자는 이스케이프하며 클립보드의 HTML과 일반 텍스트 MIME을 분리합니다.

## 재현 가능한 검증

- `npm test`: 기존 15개와 신규 8개, 총 **23개**. 유니코드·그래핌·셀 비율·공백·HTML 이스케이프·브러시 알파·이전 설정·클립보드 MIME 검증.
- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드.
- `npm run test:browser`: 기존 이미지·영상·갤러리·올가미·색상·GIF·사이드바 회귀 + v0.3 실제 클립보드·붙여넣기·실패 대응·브러시·PNG 마스크 복원·모바일 터치·390/768/1440px 검사.
- `npm run test:ai`: 실제 양자화 모델을 Edge WASM에서 실행. 모델 다운로드 응답은 로컬에 받은 동일 바이트로 제공합니다. UI 조작이 응답하고 알파의 선택/제외 영역이 모두 존재하는지 검사합니다. `AI_GPU=1`로 WebGPU 경로를 검사합니다.
- `AI_REMOTE=1`은 로컬 모델 응답 대체를 끄고 브라우저가 실제 모델 서버에 연결하게 합니다. 외부 요청이 GET/HEAD인지, 첫 사용 전 AI 파일을 받지 않는지, 문자 밀도 변경과 보정창 재진입에 재다운로드가 없는지도 검사합니다.
- 스크린샷·다운로드·테스트 모델은 Git에서 제외된 `.qa/`에 저장합니다. 최종 배포 URL에서는 모델 GET/CORS와 빌드 Worker/WASM 경로도 확인합니다.

브라우저 검증은 설치된 Edge를 사용합니다. 다른 브라우저 및 실제 iOS/Android 기기 전체를 검증했다는 의미는 아닙니다.
