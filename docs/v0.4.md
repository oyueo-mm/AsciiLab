# v0.4 편집 경험과 복사 출력

## 문자 밀도

새 이미지와 설정 초기화는 80열, 새 영상과 영상 설정 초기화는 70열을 사용합니다. 단순 50 / 보통 80 / 정밀 120 / 초정밀 180열 프리셋과 기존 슬라이더가 같은 `columns`를 조절합니다. 프리셋 외의 값은 사용자 지정으로 표시합니다. 슬라이더 범위는 이미지 40–260열, 영상 40–200열을 유지합니다.

갤러리에서 읽은 `columns`는 기본값으로 덮어쓰지 않습니다. 기존 120열 작품, 마스크와 명암 설정을 그대로 복원합니다. v0.3의 IndexedDB 스키마, PNG 마스크 저장, ormbg 모델과 라이선스는 변경하지 않았습니다.

## 복사와 출력

기본 복사 형식은 **이미지 복사**입니다. 드롭다운에 현재 형식을 표시하고 기존 복사 버튼으로 실행합니다.

| 형식      | 유지되는 내용                                                             | 한계                                                                                                                |
| --------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 이미지    | 편집 Canvas의 실제 PNG 픽셀·해상도·색상·글자 배치·투명 배경               | 붙여넣는 프로그램이 이미지를 지원해야 하며 실제 문자는 편집할 수 없음                                               |
| 서식 포함 | `text/html`과 `text/plain`, 인라인 글꼴·크기·고정 셀 폭·색상·배경·줄 간격 | 외부 프로그램이 CSS를 제거하거나 글꼴을 대체하면 모양이 달라질 수 있음                                              |
| 텍스트    | 원래 유니코드 문자, 행, 줄바꿈과 후행 공백                                | 일반 텍스트는 글꼴·색상·고정 셀 폭을 강제할 수 없음. 한글과 ASCII 공백을 섞으면 프로그램별 정렬 차이가 생길 수 있음 |

복사 전용 폭은 기본 80열이며 40 / 60 / 80 / 100 / 120열을 선택할 수 있습니다. 텍스트 보기 또는 텍스트/서식 포함 형식 선택 시 폭 선택을 표시합니다. 원본 이미지와 캐시된 마스크를 해당 폭으로 다시 샘플링하므로 단순한 잘라내기나 자동 줄바꿈이 아닙니다. 편집 슬라이더와 독립적이고 AI 재추론을 하지 않습니다.

‘텍스트’ 보기는 실제 복사 프레임의 HTML을 사용합니다. 서식 포함 클립보드도 같은 이스케이프·인라인 스타일 생성 함수를 사용합니다. 고정 셀 폭, 줄 간격과 유니코드 처리를 공유하며 긴 행은 가로로 스크롤합니다. 직접 선택과 Ctrl+C도 지원합니다. `TXT`와 `HTML` 파일도 복사 전용 프레임을 사용해 텍스트 복사와 TXT 내용을 일치시킵니다. PNG와 갤러리 작품은 편집 밀도의 프레임을 사용합니다.

HTML은 사용자 문자를 이스케이프합니다. 일반 텍스트 MIME에 HTML이나 이미지 데이터를 섞지 않습니다. 클립보드 권한/형식 지원 문제는 알림으로 안내하고 텍스트 보기에서 직접 선택할 수 있게 합니다. 기존 Ctrl+V 이미지 업로드와 입력창의 기본 붙여넣기를 유지합니다. Windows의 클립보드는 LF를 CRLF로 반환할 수 있습니다.

## 설정 패널과 작업 공간

이미지·영상 화면의 ‘변환 설정’ 버튼은 오른쪽 패널의 전체 너비를 회수하거나 복원합니다. 설정을 언마운트하지 않고 `inert`와 `aria-hidden`으로 숨겨 작업 상태와 키보드 접근성을 유지합니다. 패널 상태는 `localStorage`에 저장하며 페이지 이동·새로고침 후 복원합니다. 저장소가 제한되면 현재 세션의 React 상태로 동작합니다.

변환 영역 / 해상도 / 문자 / 톤과 색상은 개별 버튼으로 접고 펼칩니다. 여러 그룹을 함께 열 수 있고 닫힌 입력은 값을 유지합니다. 버튼의 `aria-expanded`, Enter·Space 조작을 지원합니다. 개별 그룹 상태는 현재 화면에서 유지하며 갤러리 작품 설정에는 포함하지 않습니다.

데스크톱에서는 패널만 별도로 스크롤하고 캔버스와 내보내기는 화면 안의 작업 영역을 사용합니다. 모바일은 하단 설정 영역을 접고 펼치며, 설정 영역 자체의 높이와 스크롤을 제한합니다. 검정·흰색·민트색과 기존 글꼴을 유지합니다.

## 미리보기 배율

확대·축소, 100%, 화면 맞춤과 현재 배율을 제공합니다. 수동 배율은 25–400%입니다. 화면 맞춤은 종횡비를 유지하면서 공간을 최대한 사용하므로 아주 작은/큰 작품에서는 이 범위 밖의 맞춤 배율도 가능합니다.

`ResizeObserver`가 각 뷰포트의 크기를 관찰해 패널·창 크기·밀도·원본/ASCII/비교 보기 변화에 맞춥니다. 비교 보기에서는 두 결과를 각 영역에 맞춥니다. 배율 표시는 ASCII 영역을 기준으로 하며 원본 단독 보기에서는 원본을 기준으로 합니다. 확대 상태에서 드래그로 이동하고 Ctrl+휠과 두 손가락 핀치도 지원합니다. Ctrl 없는 휠은 기본 스크롤을 유지하고 맞춤 상태의 한 손가락 세로 스크롤도 허용합니다.

배율은 CSS 변환만 변경합니다. Canvas의 픽셀 크기, ASCII 재변환, PNG·TXT·HTML 파일은 줌 때문에 변경되지 않습니다. 새 이미지나 영상을 업로드하면 화면 맞춤으로 돌아갑니다.

## 검증

- 단위 테스트 26개 통과: 새 기본값·저장 밀도 보존·화면 맞춤 종횡비·배율 제한·커서 중심 줌 좌표, 기존 ASCII·마스크·유니코드·클립보드·도넛 테스트.
- 기존 브라우저 테스트: 이미지·영상 업로드/재생/탐색, PNG/TXT/HTML, 갤러리 저장/복원/삭제, GIF 첫 프레임, 색상 제거·올가미·AI 보정, 사이드바·도넛, 한글과 실제 클립보드.
- v0.4 브라우저 테스트: 프리셋 동기화, 패널 공간 회수·상태 복원, 개별 그룹 키보드 조작, 100%·확대·축소·Ctrl+휠·드래그·핀치, 줌 전후 PNG 동일성, 복사 폭 재변환과 마스크 공백, HTML/텍스트 MIME, 실제 PNG 클립보드의 모든 RGBA 픽셀 일치, 390/768/1440px 레이아웃.
- `npm run test:ai`: 기존 실제 ormbg 추론 테스트. WebGPU와 WASM 경로를 유지하며 메모리의 마스크 재사용을 확인합니다.

TypeScript 검사와 프로덕션 빌드, 실제 ormbg의 WASM·WebGPU/WASM 추론을 통과했습니다. 개발 환경에서 모델 전달·로딩·추론까지 WASM 약 13.6초, WebGPU/WASM 약 15.6초를 관측했습니다. 모델은 로컬에 받은 동일 바이트로 제공했으며 첫 인터넷 다운로드 속도를 포함하지 않습니다. 이는 단일 개발 환경의 기능 검증이고 기기별 성능 보장은 아닙니다.

실행은 README의 개발 서버/`TEST_URL` 안내를 따릅니다. 화면 캡처와 검증 파일은 `.qa/v04/`에 저장합니다. 브라우저 검증은 Edge와 터치 시뮬레이션을 기준으로 하며 모든 외부 편집 프로그램의 붙여넣기 결과를 보장하지 않습니다.
